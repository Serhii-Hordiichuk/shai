# 📏 Правила та конвенції

Обов'язкові для всіх, хто пише код у цьому репозиторії. Порушення = зауваження в рев'ю.

---

## 1. Архітектурні заборони (з ТЗ)

| ❌ Заборонено | ✅ Замість цього |
|---|---|
| React/Vue/Angular у логіці | DOM API + ES Modules у `src/*.ts` |
| Класичний сервер (Node/Express) | Edge-функції у `edge/` |
| Сторонні UI-бібліотеки | Кастомні компоненти в `ui.ts` |
| `alert()` / `confirm()` / `prompt()` | `Modal`, `confirmDialog`, `promptDialog` з `ui.ts` |
| Emoji як іконки інтерфейсу | Власні SVG у `icons.ts` через `ico("name")` |
| `eval()` / `new Function()` | Безпечні парсери (див. мат-парсер в `engine.ts`) |

## 2. Неймінг

- **Файли:** `kebab-case.ts` для модулів (`chat.ts`, `api.ts` — короткі імена без дефісів,
  історично; нові модулі можна `call-manager.ts`-стилем, якщо ім'я довге).
- **Класи:** `PascalCase` (`ChatEngine`, `EdgeRouter`).
- **Функції/змінні:** `camelCase`.
- **CSS-класи:** `kebab-case` з префіксом компонента: `comp-ta`, `msg-body`, `cb-copy`
  (префікс = зона: `comp` композер, `msg` повідомлення, `cb` код-блок, `dd` dropdown,
  `set` налаштування, `art` артефакти, `call` дзвінок).
- **Іконки:** короткі англійські іменники (`send`, `trash`, `chevronDown`).

## 3. Стан і дані

- **Стан — тільки через `store.state`.** Жодних глобальних змінних між модулями.
- Реакція на зміни — через `store.watch(paths, cb)`, не ручні синхронізації.
- Персист — у `db.ts` (IndexedDB). Ключі: `chats/all`, `settings/app`, `models/list`,
  `misc/modelId`. Нові store'и — через апгрейд-хук `IDB`.
- **Не зберігати** API-ключі в IndexedDB без шифрування — зараз живуть у
  `settings.keys` (локально, пристрій користувача); пріоритет — Edge-проксі.

## 4. Стиль коду

- TypeScript: `strict`, явні типи публічних API модулів; всередині — здоровий глузд.
- Рядки UI — **українською**; код/коментарі — українською або англійською (консистентно
  в межах файлу).
- Помилки користувачу — інлайн (повідомлення з кнопкою «Повторити», тости), не консоль.
- `console.*` — лише для розробки; у фінальному коді прибираємо.
- Асинхронність — `async/await`; стримінг — `AsyncGenerator` + `AbortSignal`
  (патерн див. у `EdgeClient.chat` і `ChatEngine.localStream`).

## 5. CSS

- Кольори/тіні/радіуси — **тільки CSS-змінні** з `:root` (обидві теми!).
  Нова змінна — одразу в light і dark.
- Адаптив: **спершу `clamp()`** для плавності; брейкпоінти — лише для структурних
  змін (drawer/шторка/приховання).
- Тач-цілі ≥44px; перевірка `@media (pointer: coarse)`.
- Без `!important`, крім позиціювання popover'ів у медіа-запитах (обмежено).

## 6. Процес

1. Нова фіча → **запис у `DECISIONS.md`** (що/чому/як) + рядок у `CHANGELOG.md`.
2. Нова іконка → `icons.ts`. Новий UI-примітив → `ui.ts`. Новий доменний модуль →
   окремий файл + секція в `ARCHITECTURE.md`.
3. Перед завершенням — `npm run build` має проходити без помилок типів.
4. Не редагувати `package.json`/`vite.config.ts` руками — тільки через інструменти
   середовища (`install_npm_packages`).
5. Коміт-меседжі: `feat:`, `fix:`, `docs:`, `style:` + короткий опис українською.

## 7. Що НЕ чіпати без потреби

- `src/App.tsx` — це міст у середовище збірки, 20 рядків, і так і лишиться.
- Сигнатуру `mountApp(root): cleanup` — на ній тримається життєвий цикл.
- Формат нормалізованого SSE (`{type: "delta"|"thinking"|"done", text}`) — контракт
  між воркером і клієнтом. Зміна = версія `models:v2` у KV-ключі.
