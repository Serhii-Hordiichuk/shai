# 🧭 Журнал рішень (що → чому → як)

> Формат запису: **Що** додано/змінено · **Чому** (проблема/вимога) · **Як** (реалізація).
> Нові рішення дописуються **в кінець** списку з датою та версією.

---

## D-01 · Vanilla JS замість фреймворків
- **Чому:** жорстка вимога ТЗ: «Без React/Vue/Angular. Усі UI-компоненти — кастомні».
- **Як:** середовище Vite+React збережено як оболонку (так налаштований збирач), але
  `src/App.tsx` — 20 рядків, які викликають `mountApp(root)` зі `src/app.ts`. Уся логіка —
  DOM API + ES Modules. Це дає і швидкість збірки Vite, і чесний vanilla у продакшні.

## D-02 · Стан на Proxy замість бібліотек
- **Чому:** ТЗ вимагає власний state management.
- **Як:** `class Store<T>` — Proxy-обгортка з колекцією підписок `watch(paths, cb)`.
  Мутація будь-якого поля → синхронний виклик релевантних watcher'ів. `setDeep()` — для
  вкладених об'єктів (налаштування) без втрати реактивності. Без deep-proxy всього дерева:
  свідомо простіше і швидше.

## D-03 · IndexedDB замість localStorage
- **Чому:** історія з зображеннями швидко перевищує ліміт localStorage (~5 МБ);
  потрібна структурованість (розмови/налаштування/кеш окремо).
- **Як:** `class IDB` — Promise-обгортка з 3 object stores. Аватари/зображення стискаємо
  до 1280px JPEG перед збереженням, щоб не роздувати БД.

## D-04 · Власний SSE-парсер
- **Чому:** бібліотечні EventSource не підтримують POST; ТЗ вимагає власний парсер.
- **Як:** `parseSSE(response, onEvent, signal)` у `api.ts`: `getReader()` → TextDecoder →
  буфер рядків → події `data: {...}` → JSON. Підтримує AbortSignal для кнопки «Зупинити».
  Вендор-специфічні формати нормалізує Edge-воркер, тому парсер один і простий.

## D-05 · Edge-проксі з ключами в ENV
- **Чому:** ключі вендорів не повинні потрапляти у браузер користувача (вимога ТЗ, безпека).
- **Як:** воркер приймає `{provider, model, messages}`, дістає ключ з `env`, підставляє у
  запит до вендора, нормалізує SSE у єдиний формат `{type, text}`. Клієнт знає лише URL
  воркера. Каталог моделей агрегується з `/v1/models` усіх провайдерів і кешується у KV
  на годину (`ctx.waitUntil` — кешуємо у фоні, не блокуючи відповідь).

## D-06 · Три режими роботи API
- **Чому:** застосунок має працювати і без воркера, і без ключів, і офлайн.
- **Як:** пріоритети в `EdgeClient.chat()`:
  1. `settings.edgeUrl` → проксі (безпечно);
  2. ключ користувача → прямий виклик вендора (зручно для розробки);
  3. `provider === "local"` або нічого немає → офлайн-рушій.
  Помилки показуємо інлайн у повідомленні з кнопкою «Повторити», без alert().

## D-07 · Кастомні SVG-іконки, жодних emoji-іконок
- **Чому:** вимога ТЗ + єдиний візуальний стиль; emoji ламають серйозний тон.
- **Як:** `icons.ts` — словник name→SVG-рядок, stroke-based, 24×24, `currentColor`.
  Використання: `ico("send")`. **Правило:** нова іконка малюється тут, не підключається
  зі сторонніх наборів.

## D-08 · Дзвінки: STT→API→TTS + barge-in через амплітуду
- **Чому:** ТЗ: «MediaRecorder → Web Speech (STT) → Edge API → TTS, підтримка barge-in».
- **Як:** `CallManager`: continuous SpeechRecognition збирає фінальні репліки →
  `getReply()` (той самий ChatEngine-шлях) → `speechSynthesis`. Barge-in: AnalyserNode
  рахує середню амплітуду; >10 кадрів поспіль голосніше за поріг 0.16 → `cancel()` TTS.
  Аватар ШІ — Canvas: спектр мікрофона (кільце), lip-sync (рот масштабується амплітудою
  TTS-стану), пульс-кільця стану. Стенограма дзвінка додається у чат повідомленням.

## D-09 · Артефакти як код-блоки ≥40 символів
- **Чому:** права колонка Qwen Studio показує «результати» — код/сторінки. Треба просте
  детерміноване правило без ML-класифікації.
- **Як:** regex по ```-блоках; мови з білого списку (html/js/ts/py/css/json/bash/sql)
  і довжина ≥40 → артефакт. HTML отримує live-прев'ю у sandbox-iframe. ID — хеш вмісту
  (детерміновано, без дублікатів між рендерами).

## D-10 · Веб-пошук через Wikipedia API
- **Чому:** «веб-пошук» має бути реальним, але без платних пошукових API і без ключів.
- **Як:** `webSearch()` у api.ts: Wikipedia REST (uk/en) → топ-5 джерел з URL і сніпетом.
  Джерела: 1) показуються чипами під повідомленням; 2) додаються у системний контекст
  промпту. Офлайн-рушій теж приймає джерела — архітектура однакова для всіх режимів.

## D-11 · Мобільний баланс: fluid-розміри замість стрибків
- **Чому:** фіксовані px на 320/390/768/1440 дають дисбаланс «на всіх девайсах».
- **Як:** ключові розміри переведено на `clamp(min, vw-пропорція, max)` (топбар, колонки,
  модель-кнопка, відступи стрічки) — розмір змінюється плавно з шириною. Брейкпоінти лишились
  лише для **структурних** змін (drawer'и, шторки). Тач-цілі ≥44px (`pointer: coarse`),
  модалки ≤640px — нижні шторки, дзвінок ≤460px — меню, інпути 16px (iOS-зум), safe-area
  через `viewport-fit=cover` + `env()`.

## D-12 · Модалки-шторки на мобільних (без другого JS)
- **Чому:** центровані модалки незручні на телефонах; писати окремий компонент — зайвий код.
- **Як:** медіа-запит ≤640px перетворює `.modal-card` на bottom-sheet: `align-items:
  flex-end`, повна ширина, заокруглення зверху, grab-handle псевдоелементом. Та сама
  розмітка, нуль змін у логіці.

## D-13 · Англійська як головна мова продукту
- **Чому:** вимога замовника — застосунок повністю англійською; документація для команди (`.serhord/`) лишається українською.
- **Як:** повний перепис UI-рядків і офлайн-рушія; `sttLang` за замовчуванням `en-US`; системний промпт інструктує модель відповідати англійською; веб-пошук переведено на `en.wikipedia.org`. Мова диктовки лишається вибором користувача в налаштуваннях.

## D-14 · Код без коментарів, компактний
- **Чому:** вимога замовника; коментарі дублювали код і швидко старіли.
- **Як:** усі `/* … */`-банери та рядкові коментарі прибрано з `src/*`, `edge/*` і `index.css`. Самодокументованість тримається на іменах (`ChatEngine`, `refreshArtifacts`) і на цій документації. Короткі пояснення нетривіальних місць живуть у `DECISIONS.md`.

## D-15 · GitHub-ready: README + MIT + CONTRIBUTING
- **Чому:** проєкт готується до публічного розміщення на GitHub.
- **Як:** `README.md` — бейджі, можливості, стек, швидкий старт (dev/build/deploy воркера), структура, примітки про браузери; `LICENSE` — MIT; `CONTRIBUTING.md` посилається на правила в `.serhord/CONVENTIONS.md`; `.gitignore` — node_modules/dist/.wrangler/.dev.vars тощо.
