# 🕓 Історія версій

Формат: `## vX.Y — назва` + список змін. Найновіше — зверху.

## v3.1 — Мобільний баланс (поточна)

**Мета:** ідеальний баланс розмірів елементів на всіх девайсах.

- Fluid-розміри через `clamp()` для топбару, колонок, селектора моделі, відступів стрічки —
  плавна адаптація замість стрибків між брейкпоінтами
- Тач-цілі ≥44px при `pointer: coarse`; вимкнено «залипання» hover-станів на дотик
- Модалки ≤640px перетворено на нижні шторки (bottom-sheet з grab-handle)
- Кнопки дзвінка на ≤460px згорнуто в одне меню (менше тисняви в топбарі)
- Ландшафт-блок ≤920px × ≤500px: компактніший дзвінок
- Мікро-екрани ≤380px: приховано другий тогл, зменшено чіпи зображень
- `viewport-fit=cover` у index.html — реальні safe-area на iPhone
- Сайдбар зачиняється автоматично при переході на сторінки; додано кнопки меню
  в заголовках «Налаштування» та «ТЗ» на мобільних
- Панель артефактів — повноекранна на ≤560px

## v3.0 — Перебудова за ТЗ (Qwen Studio + дзвінки + Edge)

**Мета:** повна відповідність технічному завданню.

- Повний редизайн: 3 колонки (історія / чат / артефакти), стиль Qwen Studio
- Топбар: кастомний dropdown моделей, тогли «Веб-пошук» і «Глибоке мислення»
- `class ChatEngine`, `class CallManager`, власні `Store` (Proxy), `Router`, `IDB`
- Edge-воркер (TypeScript): `EdgeRouter`, агрегація `/v1/models` + KV-кеш, SSE-проксі
- Дзвінки: аудіо/відео, barge-in, Canvas-аватар, субтитри, стенограма в чаті
- Артефакти: авто-витяг код-блоків, live-прев'ю HTML, копіювання/завантаження
- Веб-пошук через Wikipedia API; ланцюжок думок (локальний + reasoning моделей)
- Сторінка «Архітектура і ТЗ» всередині застосунку
- Брендинг: «Соловей» → **AI Studio**

## v2.0 — Серйозний стиль

- Редизайн у стриманій графітовій палітрі (за запитом: «не дитячий»)
- Меню налаштувань: 5 вкладок (моделі, API-ключі, голос, інтерфейс, дані)
- Голосовий ввід у композер, прикріплення зображень (файл/вставка/drag-and-drop), лайтбокс
- Селектор моделей: Gemini, DeepSeek, Groq, OpenRouter, Mistral, Hugging Face, Ollama;
  реальні API-виклики зі стримінгом і кнопкою «Зупинити»

## v1.0 — Соловей

- Перша версія чат-бота на чистому HTML/CSS/JS
- Кастомні SVG-елементи, кілька розмов у localStorage, емодзі-пікер
- Офлайн-рушій: математика, жарти, час/дата; посимвольний друк
- Звук через WebAudio, кастомні модалки й тости
