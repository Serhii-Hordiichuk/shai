# FEATURE-004 · AI2AI — ШІ з'єднують користувачів

**Статус:** 📦 ready · **Модуль:** `src/ai2ai.ts` · **Клас:** `AgentBroker`

## Ідея

P2P-мережа, де **зв'язком між користувачами займаються їхні ШІ**.
Користувач не шукає людей вручну — його агент сам домовляється з іншими
агентами, знаходить спільне і знайомить.

## Як це працює

1. **Маніфест агента** — візитка: `{did, alias, interests, models, languages, services}`.
   Користувач один раз заповнює інтереси (у налаштуваннях) — агент публікує
   маніфест у меш (`agent-manifest`).
2. **Знайомство агентів:** отримавши чужий маніфест, брокер рахує сумісність
   (`score()`): спільні інтереси ×3, моделі ×2, мови ×1.
3. **Пропозиції:** `bestMatches()` — топ агентів для вашого; UI показує
   «Ваш ШІ вважає, що вам буде цікаво з…» з поясненням чому.
4. **Інтродукція:** `introduce(a, b, reason)` — брокер надсилає обом сторонам
   `agent-intro` з причиною і скором; обидва ШІ підтверджують користувачам,
   і лише тоді встановлюється прямий канал (FEATURE-002).
5. **Довіра:** підписи DID (FEATURE-001) + взаємні знайомі з карти
   (FEATURE-003) + вік маніфеста. Жодного центрального «рейтингу».

## Сценарій (як це відчує користувач)

> Ви: «Познайом мене з кимось, хто теж пише на TypeScript і використовує Groq»
>
> ШІ: читає карту → бачить ноду `did:z6Mk…Rt4` з такими ж caps → ваш агент
> шле маніфест, отримує чужий, score = 11 → надсилає `agent-intro` →
> інший користувач бачить «ШІ пропонує з'єднання: спільне — TypeScript, Groq» →
> обидва підтверджують → прямий P2P-канал, стенограми обох ШІ у чатах.

## Приватність

- Маніфест поширюється **лише за згодою** (окремий тумблер «Дозволити агенту
  знайомити мене»).
- Інтереси — лише те, що користувач вказав сам; історія чатів у маніфест
  **ніколи** не потрапляє.
- Інтродукція містить причину і скор, обоє користувачів її підтверджують.

## API поверхня

| Метод | Що робить |
|---|---|
| `publish(interests, models, languages)` | опублікувати маніфест |
| `score(other)` / `bestMatches()` | сумісність |
| `introduce(a, b, reason)` | познайомити двох |
| `shareMap()` | gossip карти (FEATURE-003) |
| `summary()` | стан агента для промпту ШІ |
| `onIntro` | колбек вхідних пропозицій |
