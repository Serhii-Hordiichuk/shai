# FEATURE-002 · Безсерверний меш-протокол нод

**Статус:** 📦 ready · **Модуль:** `src/mesh.ts` · **Клас:** `MeshNode`

## Проблема

Зв'язок між користувачами зараз можливий лише через спільний Edge-воркер.
Потрібен канал **без жодного центрального сервера**: нода↔нода напряму,
з довірою на криптографії, а не на інфраструктурі.

## Рішення

**WebRTC DataChannel + ручний signaling через «коди-запрошення».**

```
Аліса: createInvitation() → base64-код (SDP-offer)
        ↓ (код передається будь-яким каналом: месенджер, QR, email)
Боб:   acceptInvitation(code) → base64-код (SDP-answer)
        ↓ (answer повертається Алісі тим самим шляхом)
Аліса: join(answerCode) → P2P-канал відкрито
```

- **Без сервера:** SDP-оффер/ансер містять ICE-кандидати (non-trickle), тому
  канал встановлюється двома обмінами кодами. Використовуються лише публічні
  STUN-сервери (не передають трафік, лише допомагають NAT-пробиттю).
- **Довіра:** кожен пакет — конверт `{v, from, pub, ts, type, payload, sig}`,
  де `sig` — ECDSA-підпис DID-ключа відправника. Непідписане/чуже відкидається.
- **Протокол:** `hello`/`ping`/`pong` (RTT), `nodes-gossip` (карта),
  `agent-manifest`/`agent-intro` (AI2AI), `relay` (майбутнє: чат крізь ноди).
- **Gossip:** кожна нода періодично розсилає свою карту нод — так мережа
  «знайомиться» без центрального реєстру (див. FEATURE-003).

## API поверхня

| Метод | Що робить |
|---|---|
| `createInvitation()` | оффер → код запрошення |
| `acceptInvitation(code)` | приймає оффер → код відповіді |
| `join(code)` | ініціатор завершує рукостискання |
| `on(type, fn)` | підписка: `peer-joined`, `peer-left`, `nodes-gossip`, `*`… |
| `send(did, type, payload)` / `broadcast(...)` | підписана доставка |
| `peersInfo()` | DID, аліас, RTT, час з'єднання |
| `startKeepalive()` | ping кожні 10 с |

## Обмеження (чесні)

- Симетричний NAT (корпоративні мережі) може не пробитися без TURN;
  TURN = сервер → **опційно** використовуємо Edge-воркер якTURN-подібний реле
  лише за згодою користувача (фаза 2+).
- WebRTC недоступний у деяких webview — фолбек: relay через воркер.
