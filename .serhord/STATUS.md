## Відомі обмеження (чесний список)

1. Web Speech API (STT/TTS-голоси) — лише Chromium-браузери; у Firefox/Safari дзвінки
   працюють без розпізнавання мови (показуємо зрозумілий стан).
2. Пряме Ollama-з'єднання з браузера потребує CORS на сервері Ollama
   (`OLLAMA_ORIGINS=*`); рекомендуємо Edge-проксі.
3. Артефакти-прев'ю — sandbox без `allow-scripts`-довірених джерел; зовнішні ресурси
   вантажаться за політикою iframe.
4. Ліміт IndexedDB на зображення: стискаємо до 1280px/JPEG 85% — цього вистачає,
   але розмови з сотнями картинок варто експортувати.
