## 🔴 Найближчі (v3.2)

- [ ] **Системний промпт на розмову** — поле в меню розмови («…»), зберігається в
  `ChatDoc.systemPrompt`, додається першим у `history()` (chat.ts). ~30 рядків.
- [ ] **Свайп-жести** для drawer'ів: відкриття сайдбару свайпом від лівого краю,
  закриття панелі артефактів свайпом вправо. `touchstart/touchmove` на shell, поріг 48px.
- [ ] **Індикатор «підключення до Edge»** — пігулка в топбарі: зелений (воркер онлайн),
  жовтий (прямі ключі), сірий (офлайн). `client.fetchModels` вже повертає джерело.

## 🟡 Середньострокові (v4)

- [ ] **Гілки відповідей** — стрілки «попередня/наступна» версія відповіді;
  зберігати `Msg.alternatives: Msg[]` у IndexedDB.
- [ ] **Синхронізація через Edge KV** (мульти-тенантність) — ендпоінти
  `GET/PUT /api/user/:token/chats`; токен генерується на клієнті, ключі вендорів
  лишаються серверними. Описати схему в DECISIONS.
- [ ] **Експорт розмови у Markdown** — кнопка в меню розмови, `Blob` + `<a download>`.
- [ ] **Pull-to-refresh моделей** — жест у dropdown або окремий індикатор оновлення
  каталогу з таймером TTL.
- [ ] **Гарячі клавіші** — `Ctrl+K` (пошук моделей), `Ctrl+/` (фокус на композер),
  `Alt+1..3` (перемикання колонок).
- [ ] **Швидкі команди `/`** у композері — `/жарт`, `/час`, `/очистити` з autocomplete.

## 🟢 Довгострокові (v5+)

- [ ] **Голосовий режим hands-free** — VAD (voice activity detection) замість
  амплітудного barge-in; авто-відповідь без натискань.
- [ ] **Lip-sync SDK** — заміна псевдо-амплітуди TTS на реальний віземний аналіз
  (якщо з'явиться zero-dep рішення).
- [ ] **Плагінна система моделей** — реєстр провайдерів у `providers.ts` з
  авто-документацією; сторонні вендори додаються одним об'єктом.
- [ ] **PWA** — маніфест, service worker, офлайн-встановлення (вантажимо офлайн-рушій
  першим класом, тож PWA логічно завершує офлайн-історію).
- [ ] **Тести** — Vitest для чистих модулів (`engine.ts`, `api.ts#parseSSE`,
  `store.ts`, `router.ts`); вони свідомо відокремлені від DOM саме для цього.
- [ ] **D1 замість KV** для синхронізації, якщо з'явиться реляційна потреба
  (спільні розмови, теги, пошук).
